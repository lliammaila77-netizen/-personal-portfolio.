
# Personal Portfolio Website

## Introduction
This project is a personal portfolio website developed as part of my Software Development coursework. Its purpose is to introduce me, showcase my technical skills, highlight my projects, and provide visitors with a way to contact me.

## Website Sections

The website contains the following sections:

1. **Home:** Introduces me and displays my profile picture.
2. **About Me:** Provides information about my educational background and personal interests.
3. **Skills:** Displays my technical skills and knowledge.
4. **Projects:** Showcases completed and proposed projects.
5. **Contact:** Provides my contact information and a contact form.

## Technologies Used
- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used to style the website, including colours, fonts, spacing, navigation, and layout.
- **Visual Studio Code:** Used as the code editor.
- **Git and GitHub:** Used for version control and hosting the project.
- **GitHub Pages:** Used to publish the website online.
